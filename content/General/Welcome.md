# Welcome to the Wiki

This is a **read-only**, sign-in protected wiki that renders `.md` files
straight from disk. Just drop new folders and Markdown files into the
`content/` directory and they'll show up automatically in the sidebar.

## Features

- Folder-based organization
- Full-text search across all pages
- Dark theme with a magenta accent
- No database required

## Example code block

```bash
php generate_hash.php mypassword
```

> Tip: nested folders are supported to any depth.
